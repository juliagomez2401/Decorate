# Decora.te

Web de Decora.te, accesorios de cuero hechos a mano en Uruguay.

Página estática (HTML, CSS y JavaScript). Para verla, abrir `index.html` o publicarla con GitHub Pages.

- `js/datos.js`: precios, categorías, cueros y contacto.
- `js/stock.js`: piezas en stock (se genera con `herramientas/generar-stock-js.py` a partir de `herramientas/stock.json`).
- `img/`: imágenes optimizadas para la web.
